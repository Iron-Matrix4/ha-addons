---

## 🚀 Installation

1. Go to **Settings → Add-ons → Add-on Store**
2. Click the menu (⋮) → **Repositories**
3. Add: `https://github.com/Iron-Matrix4/ha-addons`
4. Click **Add** → **Close**
5. Refresh and find the add-ons in the store
